# FlyBrain Studio · 果蝇脑活动实验室

一个可离线运行的 Windows 桌面应用。拖入本地视频，观察真实 FlyWire 连接图上的**近似脉冲模拟**，旋转、筛选和点选 139,255 个神经元。

## 直接打开

官方数据版：`release-official/FlyBrainStudio/FlyBrainStudio.exe`。已打包 Python、Qt、模拟器和数据；移动应用时移动整个 `FlyBrainStudio` 文件夹，保留 exe 旁的 `_internal`。旧版 release、release-navigation、release-bilingual 仍使用旧数据，不能用于验证本次迁移。源码仓库不包含这些应用包。

拖动左侧栏右边的分隔线调整宽度；顶部「复位布局」恢复默认宽度。「中文 / English」切换并记住界面语言。首次开源步骤见 `OPEN_SOURCE_GUIDE.md`。这是 AI 辅助开发的学习项目，尚未经过生物学验证。

启动后默认播放彩色移动光栅，并向模型输入 300 Hz 脉冲音，立即可以看到活动。将视频文件拖入窗口，或点击「打开视频」。仅处理本地视频，不上传，不需要账户。声音输入默认开启；供人耳试听的「监听原声」默认关闭。内置脉冲音只进入模型，不通过扬声器播放。

## 本次新增：颜色、声音与显示控件

- 「RGB 实验编码 / 灰度对照」改变实际进入光感受器的刺激，采样可选 64×36、128×72（默认）、256×144。
- 点击「视觉采样」可收起或展开预览；隐藏预览不会关闭输入或模拟。
- 「声音输入」单独控制音轨到神经元的刺激；「监听原声」控制供人耳参考的本地播放。监听不决定神经输入，模拟按视频时间解码声音。
- 源音轨频段能量显示四个频段；关闭声音输入时这些条仍可显示源音轨能量。无音轨或解码失败时显示原因，输入为零。
- 「静息点」「放电点」分别调整点的像素大小；「恢复点大小」恢复 1.65 px / 4.45 px。显示余辉在这两个尺寸之间插值，不改变神经脉冲。
- 「恢复输入默认」恢复 RGB、128×72、声音输入开启、声音增益 1.00、视觉输入强度 1.50、连接增益 1.50。不会跳转视频或清除神经状态。

### 必须区分的近似

当前光感受器注释只有 `photo_receptor`，没有可靠 R7/R8 子型。RGB 模式按 `root_id % 3` 为这些真实节点分配 R/G/B 输入通道。这是可重复的**人工实验编码**，没有声称这些细胞在活体中分别感受红绿蓝。灰度模式仍按亮度输入所有感受器。不能从 RGB 推算视频不存在的紫外光；R7/R8 的生物学光谱响应没有被重建。

声音只刺激数据中 393 个 `sub_class=auditory` 节点，不把风/重力或其他机械感觉神经元混作听觉输入。PyAV 解码首条音轨到 16 kHz 单声道；视频每帧结束时取前 40 ms 窗口，以 Hann 窗计算 80–200、200–400、400–800、800–2000 Hz 的频段 RMS。按 `root_id % 4` 分配频段，电流为 `clip(RMS × 声音增益 × 6, 0, 3)`。这是频段能量包络编码，不是声波相位、真实声压/触角振动或逐神经元实测调谐。复位、倒退和远距离跳转会按媒体时间重新定位解码器；缓存有界，无需完整加载长音轨。

参考依据：[果蝇光感受器光谱响应](https://www.nature.com/articles/s41598-020-74742-1)、[声音与风刺激激活不同的 Johnston's organ 神经元](https://www.nature.com/articles/nature07843)。这些研究支持区分感觉通道，**不验证本应用的人工分组参数**。

## 交互

启动默认不选中任何神经元。大白点是选中标记，周围直线是所选节点的输入/输出连接；它不表示更强的放电。点击「取消选中」、按 Esc 或点击大脑背景空白处可清除标记与连接，不删除数据。点击「视角复位」或按 Home 恢复居中的正面视角、缩放与视野，并停止自动旋转；不重置神经状态。

- 左键拖动：旋转；滚轮：缩放；Ctrl + 拖动：平移；正面 / 背面 / 俯视 / 侧面：复位相机。
- 点击神经元：查看 root ID、分类、递质预测、输入/输出数量。右侧可按 root ID 搜索、点击连接跳到相邻神经元。
- 分类与侧别筛选、仅活跃模式、活动配色、点大小、自动旋转只影响显示。整个网络仍参与模拟。
- 空格播放/暂停；Ctrl+O 打开视频；R 清零神经状态。拖动视频进度会重置模拟并从当前位置开始，**不会重建跳转位置之前的神经历史**。
- 输入强度和连接增益可以直接调整。增益较高可能导致广泛同步，这是近似模型的行为，不是生物学结论。
- 底部查看抽样栅格、全脑平均放电频率、所选神经元膜状态。
- 「导出全脑脉冲 CSV」保存最近最多 **3 个模拟秒**内全部神经元的逐脉冲时间和 root ID，另附 JSON 数据来源与参数。不是整个视频的无限记录。
- 「保存视图」导出当前界面 PNG。

## 数据真的来自哪里

当前直接下载 **FlyWire 官方 FAFB v783 成年雌性果蝇脑 CSV 发布数据**，不是 MaleCNS，也不经过第三方模拟项目。

官方地址模板 `https://storage.googleapis.com/flywire-data/codex/data/fafb/783/` 来自 [FlyWire 官方 Codex 的数据加载器](https://github.com/murthylab/codex/blob/main/codex/data/local_data_loader.py)。四个输入文件是 `neurons.csv.gz`、`classification.csv.gz`、`coordinates.csv.gz`、`connections.csv.gz`。下载器检查服务端 MD5 和长度，并记录 URL、对象版本和 SHA-256；转换器核验这些文件，应用启动时核验生成数据的 SHA-256。没有第三方数据回退。

| 内容 | 本应用的数据 |
| --- | --- |
| 神经元 | 139,255，保留真实 root ID |
| 聚合有向连接 | 2,700,513；不是 270 万个独立生物突触 |
| 官方连接表行数 | 3,869,878（按神经元对和 neuropil 分行） |
| 这些行的突触数量总和 | 34,153,566；不是全部生物突触的完整清单 |
| 有空间坐标的神经元 | 139,255 |
| 光感受器输入 | 11,153，依据 `sub_class=photo_receptor` |
| 三维点的位置 | 每个 root ID 公开标注坐标的均值，居中、统一缩放及轴变换 |
| 神经元类别 | 由公开 class / sub_class / flow 注释整理的功能集合 |

转换器先将跨 neuropil 的正整数突触数按 pre→post 求和，不附加连接强度阈值，也不根据递质正负抵消原始计数。`synapse_count` 保留无符号数量；模拟权重单独根据突触前神经元的 `nt_type` 分配符号：GABA 为负，其余包括 GLUT、调制递质与未知值为正。这是本应用的重大简化，不是官方生理结论。官方 CSV 本身可能已筛选；网页统计口径、注释时间与这里固定下载的文件不一定一致。切换官方数据不等于验证了动力学。

`data/manifest.json` 记录输入和输出文件 SHA-256。坐标是标注点，**不是 soma 定位、神经元骨架或脑区表面网格**。连接在界面中画成直线，最多显示所选神经元各 160 条较强输入与输出。

原始研究：Dorkenwald et al., *Neuronal wiring diagram of an adult brain*, Nature (2024), https://doi.org/10.1038/s41586-024-07558-y 。数据门户：https://codex.flywire.ai/ 。数据原始权利和条款独立于本项目代码许可证，见 `THIRD_PARTY.md`。

## 模型与显示的边界

所有 139,255 个节点和这份快照的所有边参与稀疏矩阵传播，计算在后台线程进行；没有随机生成的脉冲或随机点云。

使用归一化 leaky integrate-and-fire 模型：dt=10 ms，膜时间常数 30 ms，阈值 1，重置值 0，20 ms 不应期，固定背景驱动 0.02；上一时间步的脉冲经有向连接传到下一步。权重按 `sign(w)*log1p(abs(w))/sqrt(sum(abs(incoming)))` 变换，默认连接增益 1.5。视频灰度输入乘以 `0.48 × 输入增益`，默认输入增益 1.5。无训练或学习规则。

每一视频帧按其 FPS 推进相应模拟时间。计算来不及时播放自然变慢，不通过跳过神经状态来伪装实时。倍速改变播放节奏；变量帧率视频使用解码器报告的平均 FPS，长片可能有时间偏差。供人耳监听的 Qt 播放器会定期纠偏；模拟明显慢于实时或跳转时试听可能有间断，但神经声音输入仍按视频时间取样。

感受器依据左右侧标注和二维投影坐标近似采样 RGB 或灰度画面，两眼均接收这块屏幕。**没有测量真实复眼感受野，也没有还原活体神经动力学。** 结果适合交互实验和学习，不能当作“真实果蝇看同一视频时的实际脑活动”。

3D 颜色亮度使用真实计算出的放电计数和短暂的显示余辉。底部栅格按分类确定性抽样最多 256 个神经元，每列是一个显示窗内的脉冲计数；界面漏掉后台帧时用累计差补全。全脑平均频率用全部脉冲数 / 全部神经元数 / 模拟时间计算。选中神经元曲线是显示采样的归一化膜状态，不是 mV 电生理记录。

## 从源码运行与构建

在项目目录内，Python 3.14（本次测试环境）：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python scripts/download_data.py
.venv\Scripts\python scripts/prepare_data.py data/raw/783 data
.venv\Scripts\python main.py
```

运行模型测试与真实媒体/Qt 交互测试：

```powershell
.venv\Scripts\python tests/test_model.py
.venv\Scripts\python tests/test_data_pipeline.py
.venv\Scripts\python tests/test_senses.py
.venv\Scripts\python tests/desktop_smoke.py test-output
```

重新从官方获取并重建数据（需要联网下载，之后可离线运行）：

```powershell
python scripts/download_data.py data/raw/783
python scripts/prepare_data.py data/raw/783 data
```

打包：安装 `pyinstaller==6.22.3` 后运行 `scripts/build.ps1`。Qt/OpenGL 需要系统图形驱动支持。源码、数据和可执行程序分别存放，便于后续接入更精确视觉编码、神经元骨架和其他连接组。

源码仓库只存下载/转换脚本与来源清单，不提交原始 CSV 或生成的 NPZ。FlyWire 数据按其独立的 CC BY-NC 4.0 条款使用与署名，不能由本项目 MIT 许可证改成无限制商用。见 `THIRD_PARTY.md`。

当前未实现：完整轴突/树突形态、生理校准的色觉/听觉、实时摄像头、身体、学习模型、从任意进度恢复完整神经历史。旧 HTML 与 toy 项目已退出使用。
